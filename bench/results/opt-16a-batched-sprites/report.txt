== Method
Client alone (no server), pinned to CPUs 4-7, vsync on (glfwSwapInterval(1)).
Each run draws the floor (130 tiles) + N animated stress sprites for 1200 frames,
then prints the CPU time of render_frame() per frame (clock_gettime around the
call; GPU work and buffer swaps are not included).
Modes: immediate = one glBegin/glEnd per sprite (--render-immediate, before);
batched = one vertex array and one glDrawArrays per frame (after).
5 runs per mode and N, interleaved. perf stat counts the whole process
(all threads, including the GL driver's) from 3 s after start, so start-up is excluded.
