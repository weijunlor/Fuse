== 2. Scenario
1 server + 4 clients on one machine, moving: every client holds right, down, left, up for 1 s each (FUSE_AUTO_MOVE=1),
sending ~100 input messages/s like a held arrow key.
Server pinned to CPUs 0-3, clients to CPUs
4-15 (P-cores only). Program output goes to /dev/null.
Every measurement starts fresh processes, waits 5 s (joining finishes),
attaches perf to the process by PID, then kills everything.
